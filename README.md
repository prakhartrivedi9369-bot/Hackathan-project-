**AI-powered Disaster Response & Emergency Coordination Platform**

**Project Status:** Active Development

GuardianMesh AI is a modern web platform designed to improve disaster management by connecting governments, emergency responders, NGOs, hospitals, volunteers, and citizens through AI-powered insights, real-time mapping, and intelligent resource coordination.

This project is currently being developed as part of a hackathon and is under continuous improvement.

---

## Features

- Modern responsive landing page
- AI Disaster Prediction (UI)
- Live Disaster Alerts
- Interactive Disaster Map (Leaflet)
- Shelter Finder
- Volunteer Network
- Government Dashboard
- Analytics Dashboard
- Dark / Light Theme
- Fully Responsive Design
- Smooth UI Animations

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd GuardianMess-ai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Vision

The objective is to enable faster decision-making, improve collaboration between emergency agencies, and enhance public safety during disasters.
